Cómo obtener las credenciales:
1. Ve a console.firebase.google.com
2. Crea un proyecto (gratis) → Realtime Database
3. Reglas: read/write: true (para uso privado)
4. Clic en Configuración del proyecto → Agregar app web
5. Copia los valores del objeto firebaseConfig
